# ERP Solutions

## Description
This is an ERP-based web application built using ASP.NET Core MVC.

## Features
- Sales order processing
- Shopping cart system
- Dynamic menu system

## Tech Stack
- ASP.NET Core MVC
- C#
- SQL Server
- ADO.NET
- HTML, CSS
- JavaScript / jQuery
- Bootstrap
